🍎 iOS Shortcut (tavsiya etiladi!)

iOS Shortcut orqali bitta tugma bosib clipboard'ni PCga yuborasiz. Brauzer ochish shart emas!

  1. iPhone'da Shortcuts (Yorliqlar) ilovasini oching
  2. "+" bosib yangi shortcut yarating.
    "Add Action" → "Get Clipboard" qo'shing
  3. Yana "Add Action" → "Get Contents of URL" qo'shing.
    URL maydoniga pastdagi manzilni yozing:
    Yuklanmoqda...
  4. "Get Contents of URL" ni bosing:
    • Method: POST
    • Request Body: File
    • File: Clipboard (oldingi action natijasi)
  5. Shortcut'ga nom bering: "PC ga yuborish"
    • Tepadagi ▼ belgini bosing → "Add to Home Screen"
  6. Tayyor! Endi istalgan joyda copy qilib, home screen'dagi ikonkani bosasiz — avtomatik PCga tushadi!
💻 PC → Telefon (PC clipboard olish)

PC clipboard'ini olish uchun yana bitta shortcut yarating:

  1. Yangi Shortcut → "Get Contents of URL" qo'shing.
    URL:
    Yuklanmoqda...
  2. "Copy to Clipboard" action qo'shing.
    Natija avtomatik clipboard'ga tushadi.
  3. Nom: "PC dan olish", Home Screen'ga qo'shing.
