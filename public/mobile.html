🍎 iOS Shortcut (recommended!)

Send clipboard with one tap via iOS Shortcut. No browser needed!

  1. Open Shortcuts app on your iPhone
  2. Tap "+" to create new shortcut.
    "Add Action" → "Get Clipboard"
  3. Add "Get Contents of URL". Set URL to:
    Loading...
  4. "Get Contents of URL" settings:
    • Method: POST
    • Request Body: File
    • File: Clipboard
  5. Name the shortcut. Tap ▼ → "Add to Home Screen"
  6. Done! Copy anything, tap the icon → instantly synced to PC!
