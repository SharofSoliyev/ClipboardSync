Quick Start

  1. Scan the QR code with your phone (or open the URL in browser)
  2. Type or paste text on your phone — it syncs to your computer automatically
  3. Text copied on your computer appears on your phone automatically
  4. Both devices must be on the same Wi-Fi network!

⭐ What is ClipSync?

ClipSync is a tool that syncs clipboard between your phone and Windows computer. Like Apple's Universal Clipboard — but for Windows.

📝 TextSync text in any language (Cyrillic, Latin, CJK...)
🎨 ImagesPNG, JPEG, GIF, WebP, BMP clipboard support
⚡ Real-timeInstant delivery via WebSocket
🔒 SecureUUID token, works only on local network
🔄 BidirectionalPC → Phone and Phone → PC
🍎 iOS ShortcutSend with one tap, no browser needed

Windows Install on Computer

Requires Node.js (v16+)

1
Clone the project
git clone https://github.com/SharofSoliyev/ClipboardSync.git
2
Enter folder
cd ClipboardSync
3
Install dependencies
npm install
4
Start the server
npm start

Or double-click start.bat
