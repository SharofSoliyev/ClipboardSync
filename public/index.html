⭐ ClipSync nima?

ClipSync — telefoningiz va Windows kompyuter o'rtasida clipboard'ni sinxronlash vositasi. Huddi Apple'ning Universal Clipboard xususiyati — faqat Windows uchun.

📝 MatnHar qanday tildagi matnni sinxronlash (kirill, lotin, xitoy...)
🎨 RasmlarPNG, JPEG, GIF, WebP, BMP rasmlarni clipboard'ga o'rnatish
⚡ Real-timeWebSocket orqali bir zumda yetkazish
🔒 XavfsizUUID token, faqat lokal tarmoqda ishlaydi
🔄 Ikki tomonlamaPC → Telefon va Telefon → PC
🍎 iOS ShortcutBrauzer ochmasdan bitta tugma bilan yuborish

Windows Kompyuterga o'rnatish

Oldin Node.js (v16+) o'rnatilgan bo'lishi kerak.

1
Loyihani yuklab olish
git clone https://github.com/SharofSoliyev/ClipboardSync.git
2
Papkaga kirish
cd ClipboardSync
3
Bog'liqliklarni o'rnatish
npm install
4
Serverni ishga tushirish
npm start

Yoki start.bat faylni ikki marta bosing.

📱 Telefonni ulash

1
Telefon va kompyuter bitta Wi-Fi tarmoqda bo'lishi kerak
2
Dashboard'dagi QR code'ni telefoningiz bilan skanerlang
3
Mobil sahifada clipboard sinxronlashni boshlang!

iOS iOS Shortcut sozlash (tavsiya etiladi!)

Brauzer ochmasdan bitta tugma bosib clipboard'ni PCga yuborasiz.

1
iPhone'da Shortcuts (Yorliqlar) ilovasini oching
2
"+" bosib yangi shortcut yarating. "Add Action" → "Get Clipboard" qo'shing
3
Yana "Add Action" → "Get Contents of URL" qo'shing. URL maydoniga:
Yuklanmoqda...
4
"Get Contents of URL" sozlamalarida:
  • Method: POST
  • Request Body: File
  • File: Clipboard (oldingi action natijasi)
5
Shortcut'ga nom bering: "PC ga yuborish"
Tepadagi ▼ belgini bosing → "Add to Home Screen"
6
Tayyor! Endi istalgan joyda copy qilib, home screen'dagi ikonkani bosasiz → avtomatik PCga tushadi!

💡 Back Tap (bonus)

Settings → Accessibility → Touch → Back Tap → Double Tap → yaratgan Shortcut'ingizni tanlang.

Endi telefonning orqasiga 2 marta tiqillatib clipboard yuborasiz!

🔌 API Endpointlari

Boshqa ilovalar yoki skriptlar bilan integratsiya qilish uchun:

Endpoint Method Tavsif
/api/send GET/POST Matn yoki rasm yuborish
/api/get GET PC clipboard'ini olish
/api/clipboard GET/POST JSON formatda clipboard boshqarish
/api/image GET Oxirgi rasm
/ws WebSocket Real-time sinxronlash

Barcha endpointlarga ?token=YOUR_TOKEN qo'shish kerak.
