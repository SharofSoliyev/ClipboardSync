# Contributing to ClipSync

Thank you for your interest in contributing to ClipSync!

## How to Contribute

### Reporting Bugs

1. Check existing [issues](https://github.com/SharofSoliyev/ClipboardSync/issues) first
2. Create a new issue with:
   - Clear title describing the bug
   - Steps to reproduce
   - Expected vs actual behavior
   - Your OS version, Node.js version, and phone model

### Suggesting Features

Open an issue with the `enhancement` label describing:
- What problem the feature solves
- How you envision it working
- Any alternatives you've considered

### Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly on both PC and phone
5. Commit with clear messages
6. Push and create a Pull Request

### Development Setup

```bash
git clone https://github.com/SharofSoliyev/ClipboardSync.git
cd ClipboardSync
npm install
npm start
```

### Code Style

- Use clear, descriptive variable names
- Keep functions small and focused
- Add comments for non-obvious logic
- Test with both iOS and Android devices when possible

### Areas for Contribution

- Additional language translations (i18n)
- macOS / Linux support
- Improved image handling
- Encryption for clipboard data
- Auto-start on Windows boot
- Browser extension for easier access
